# TINT Ontology

TINT is a planned public knowledge and search platform for AYUSH and traditional
home-remedy information. It is designed around an ontology-backed, multilingual
knowledge graph and a moderated practitioner contribution workflow.

The project is currently in **Phase 5: production launch foundation**.

## Guiding rule

The platform is a verified knowledge and guidance service, not a diagnosis or
prescription service. Practitioner submissions remain separate from published
knowledge until reviewed and approved.
