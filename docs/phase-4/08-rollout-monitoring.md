# Phase 4 Step 8: Rollout Monitoring

This step adds a protected rollout monitoring page at
`/admin/pilot/monitoring`.

## Monitoring signals

- Sign-off status.
- Safety feedback.
- Validation blockers.
- Action closure.
- Audit posture.
- Publication throughput.

The dashboard also provides a weekly cadence for controlled rollout governance.
It is linked from the pilot dashboard and the scale-up plan.
