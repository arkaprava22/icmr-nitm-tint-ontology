# Phase 4 Step 7: Scale-up Plan

This step adds a protected scale-up planning page at `/admin/pilot/scale-up`.
It translates the current pilot recommendation, latest sign-off, readiness
gates, validation records, and pilot actions into rollout workstreams.

## Workstreams

- Knowledge expansion.
- Practitioner onboarding.
- Safety monitoring.
- Operational scale.

Each workstream includes a readiness status, owner, objective, current signal,
and next milestone. The page is linked from the pilot dashboard and evidence
pack.
