# Phase 4 Step 1: Pilot Readiness

This step introduces an administrator-facing pilot readiness dashboard for the
TINT AYUSH ontology application. It gives the project team a single view of the
conditions that should be checked before stakeholder validation.

## What is covered

- Audit integrity across privileged workflow events.
- Automated validation status for practitioner submissions.
- Publication baseline for public search walkthroughs.
- Citizen safety and quality feedback triage.
- Evidence strengthening needs for weak or practitioner-only sources.
- Reviewer capacity and decision activity.

## Readiness meaning

- **Ready**: suitable for inclusion in pilot validation.
- **Needs attention**: usable for internal testing, but should be improved before
  a wider validation group.
- **Blocked**: should be resolved before formal pilot validation.

The dashboard is available at `/admin/pilot` for authenticated administrators.
It does not change records; it summarizes the state of existing governance,
review, evidence, publication, feedback, and audit controls.
