# Phase 5 Step 1: Production Readiness

Phase 5 begins with a protected administrator page at `/admin/production`.
The page converts the Phase 4 handover into a launch-readiness view for a
public countrywide service.

## Purpose

- Separate pilot/demo readiness from production launch readiness.
- Make infrastructure, security, ontology, safety, monitoring, operations, and
  governance gaps visible in one place.
- Give administrators a launch sequence that can guide the next implementation
  steps.

## Readiness Areas

- Production data store
- Identity and access
- Validated ontology baseline
- Safety operations
- Observability
- Audit integrity
- Launch support
- Pilot handover

## Launch Sequence

- Confirm production infrastructure and data migration design.
- Replace demo account flows with controlled onboarding and access recovery.
- Freeze the first validated ontology release baseline.
- Activate monitoring, safety triage, audit review, and support runbooks.
- Run one final governance review before public launch.

## Validation

The validation suite checks the production readiness data function, admin route,
navigation from the admin dashboard, and handover-to-production link.
